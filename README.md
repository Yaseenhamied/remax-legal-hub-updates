# REMAX Legal HUB — installers and updates

This repository holds only the Windows installers for **REMAX Legal HUB**, the REMAX Libya contracts app. It has no source code and no data.

- **First install:** download `REMAX-Legal-HUB-Setup-<version>.exe` from the latest release and run it. No administrator rights are needed.
- **Updates:** the app finds new versions here by itself (Settings → Updates). It checks each download against the SHA-256 in `latest.json` before installing.

Windows may show "Windows protected your PC" because the installer isn't code-signed yet. Choose **More info → Run anyway**.
